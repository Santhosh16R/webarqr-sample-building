# Third-party libraries

This site vendors pinned open-source browser libraries so there are no runtime CDN requests.

- MindAR 1.2.5 — https://github.com/hiukim/mind-ar-js/tree/v1.2.5 — MIT; see `vendor/mindar/LICENSE`.
- Three.js 0.147.0 — https://github.com/mrdoob/three.js/tree/r147 — MIT; see `vendor/three/LICENSE`.
- MindAR's bundled dependencies retain their upstream licence banners, including TensorFlow.js (Apache-2.0). Upstream dependency declarations: https://github.com/hiukim/mind-ar-js/blob/v1.2.5/package.json

The building model and Building 01 tracking image were created for this project.
